본문으로 건너뛰기
>_ cli-tools 홈으로 돌아가기

2026.08.03 업데이트

개인정보 처리 안내

cli-tools 웹사이트는 가입, 결제, 문의 양식을 운영하지 않으며 방문자를 식별하는 자체 분석 도구를 사용하지 않습니다.

사이트가 저장하는 항목

테마 선택은 현재 브라우저의 localStorage에만 저장됩니다. 이 값은 서버로 전송되지 않으며 브라우저 설정에서 언제든 삭제할 수 있습니다.

명령어 복사

복사 버튼은 브라우저 Clipboard API를 사용합니다. 복사한 명령과 클립보드 내용은 cli-tools 웹사이트로 전송되지 않습니다.

호스팅과 외부 링크

사이트는 GitHub Pages에서 제공됩니다. GitHub는 서비스 운영에 필요한 요청 정보를 처리할 수 있으며, 자세한 내용은 GitHub 개인정보 보호 정책 에서 확인할 수 있습니다.

변경 사항

데이터 처리 방식이 달라지면 이 페이지의 설명과 업데이트 날짜를 함께 수정합니다.
